# Главная MMD — аккуратное обновление дизайна

Откройте index.html двойным щелчком: сборка и установка пакетов не нужны.

Сохранены содержание, порядок блоков, цена, контакты, логотип и фотографии главной https://03.com.ru/ на момент просмотра 20.10.2026. Разделы: первый экран, о нас, лицензии, полезно знать, заявка, отзывы, подвал. Ссылки на внутренние страницы ведут на действующий сайт.

Что изменено:
- Единая сетка и интервалы, спокойная типографика без сплошного верхнего регистра в основном заголовке.
- Светлая шапка, заметный телефон, красная основная кнопка.
- Мягкие фоновые подложки и скругления вместо тяжёлых декоративных элементов.
- Адаптивные колонки, мобильное меню, видимый фокус клавиатуры.
- Лицензии и письма отображаются все сразу; нажатие открывает крупное изображение.

Файлы:
- index.html — готовая разметка.
- styles.css — оформление и адаптивность.
- app.js — меню, окно заявки, просмотр документов.
- assets/ — локальные изображения исходного сайта.
- preview-desktop.png — снимок готовой страницы.
- mobile-check.html — стенд просмотра страницы шириной 390 px.
- original-reference.txt — исходный HTML для сравнения.
- prepare.cjs — служебный скрипт, использованный при подготовке; повторный запуск не нужен.
- preview.cjs — необязательный локальный сервер: node preview.cjs, адрес http://127.0.0.1:8030.

Это самостоятельный локальный макет. Формы проверяют обязательные поля, но не передают данные; при отправке появляется честное сообщение, что заявка не отправлена. При внедрении необходимо подключить существующий серверный обработчик, защиту от спама и аналитику. Скрипты аналитики исходного сайта в макете отсутствуют. Цена, год в подвале и утверждения о лицензиях сохранены из оригинала; актуальность не проверялась.

## Адаптивная вёрстка
Обе страницы подключают responsive.css последним. Диапазоны: 320–359, 360–580, 581–767, 768–1023, 1024–1100, 1101–1599 и 1600+ CSS px. Максимальная ширина контента 1280/1360 px, поэтому на Full HD текст не растягивается на весь экран. При увеличении масштаба браузера применяются правила для доступной ширины.

Добавлены мобильное меню до 1023 px, адаптивные формы и футер, целые фотографии на узких экранах, прокрутка отзывов, размеры окон относительно динамической высоты экрана, поля ввода 16 px для предотвращения автоматического масштабирования на iPhone. Выполнены проверки ссылок на локальные ресурсы, подключения стилей, структуры CSS и синтаксиса JavaScript. Визуальная проверка в браузере на всех размерах не выполнена.
